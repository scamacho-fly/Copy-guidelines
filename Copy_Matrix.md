# Core Messaging Themes

## Everyday Value

Flybuys helps members get more value from their everyday spending.

Key messaging:

- Make your regular shops remarkable.
- Get more value from everyday spending.
- Earn points on everyday purchases.
- Turn points into rewards.

- Travel sooner

# Copy Review Checklist

- Focuses on member value.
- Uses simple language.
- Uses Flybuys-approved terminology.
- Highlights rewards and benefits.
- Includes a clear action.
- Maintains consistency with Flybuys messaging.
- Reinforces earning, saving or rewarding outcomes.
