# Flybuys Copy Matrix Knowledge Base

## Overview

This repository contains the Flybuys Copy Matrix knowledge base, a central source of truth for UX, UI, product, and marketing copy.

The purpose of this knowledge base is to ensure consistency across Flybuys experiences by documenting approved messaging patterns, terminology, headlines, calls to action, and content frameworks used throughout the Flybuys ecosystem.

This document is intended to support:

- UX Writers
- Product Designers
- Content Designers
- Marketing teams
- Product Managers
- AI-powered copy assistants
- Design System contributors

---

## Purpose

The Flybuys Copy Matrix provides guidance for creating clear, consistent, and customer-focused copy across digital experiences.

It helps teams:

- Maintain a consistent Flybuys voice and tone
- Reinforce member value and rewards
- Standardise terminology and messaging
- Improve customer understanding and engagement
- Reduce content duplication and inconsistency
- Scale content creation across channels
